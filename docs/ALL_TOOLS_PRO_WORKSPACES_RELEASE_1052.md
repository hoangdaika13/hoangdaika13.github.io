# All Tool Pro Workspaces — release 1052

Continues release 1051 in the existing HH Platform shell. All 86 tool identifiers, dedicated routes, auth and unrelated workspaces are retained. No global theme change, new login, paid automatic request or external browser CDN has been introduced.

## Implemented

- Monaco Editor 0.55.1 is actually shipped under a pinned same-origin path, lazily opened on desktop: multiple documents, language formatting, syntax diagnostics, find/replace, read-only saved/current diff, save/export and disposal of models/workers. Mobile deliberately uses a native textarea because upstream Monaco does not officially support mobile. See `ALL_TOOLS_MONACO_RUNTIME.md` for integrity, MIT notices and size.
- Prompt Library supports editing existing records, tags/search/favorites/duplicates, strict JSON import/export and reusable `{{variables}}`. Workspace Tabs rename/reorder and protect unsaved text. Version restore and file editing retain safety snapshots. File Explorer adds folders/search/move and safe text editing; uploaded HTML/SVG are not executed.
- JSON Viewer has a bounded expandable typed tree, search, RFC 6901 path/value copy and full JSON export. Markdown Editor has block preview, toolbar, lists/checklists/tables/code/links and `.md`/HTML export. Raw HTML is escaped, external images do not load, exported HTML has a restrictive CSP.
- API Tester adds query parameters, real status/time/byte display, response tabs, HEAD/OPTIONS, bounded body/response, timeout and cancel. Browser CORS is not bypassed, cookies are omitted, redirects/retries are disabled and sensitive forms/responses are not saved.
- Calendar has actual month/week/list navigation, date selection, edit, duration/location and UTC ICS export with escaped/folded lines. Notes add Markdown preview/export. Todo/Kanban add priority/tags/due/filter/sort. Revision conflicts preserve the draft; collection limits reject a new item rather than silently dropping old items. Reminders can snooze and opt into foreground notifications, never background delivery.
- Favorite Manager and the catalog share stars/pins/recents immediately. Search and keyboard Command Palette cover the real catalog/actions. History aggregates bounded action metadata, not private tool contents. Local notification changes can signal other tabs of the same account; remote Web Push is not claimed.
- Export/Import v2 has explicit account and selected scopes across Platform, utilities, workspace, catalog and appearance. Full validation precedes writes. Workspace IndexedDB uses one three-store transaction; cross-store import uses bounded snapshots and logical rollback, reporting a rollback failure as partial, not atomic success. File bytes are opt-in: 1 MiB/file, 2 MiB aggregate, 4 MiB common envelope/5 MiB Platform export. Omitted binaries are listed and retained. Imports including files are refused if original binaries cannot fit the rollback snapshot. Existing v1 import remains supported; old unowned workspace data is not adopted automatically.
- Offline Mode really downloads only selected public JS/CSS into `hh-alltools-offline-v2`, bounded to 15 MiB; that cache survives normal release activation. It does not cache auth/API/private file data or claim full-site/server offline functionality.
- Existing `/api/ai` now includes authenticated uploaded-audio transcription and downloadable WAV synthesis adapters. Each requires `consent.paidProcessing === true`, bounded input, one provider attempt, no retry/autoplay. Binary audio/transcript are returned only to the caller, never persisted in gateway job metadata. Device voices and backend WAV remain distinct.
- Final review fixes keep newer matching Workspace Tabs drafts after hard reload, preserve File Explorer text across rename/move/reload, block silently opening another file with pending edits and reject stale-file overwrites. Legacy numeric-string font scales are normalized without adopting invalid settings; new theme writes are numeric. Offline inspection checks the exact current asset URL, including its version.

## Speech configuration and privacy

Uses the already configured server-side `GEMINI_API_KEY`, `GOOGLE_AI_API_KEY` or first `GEMINI_API_KEYS` key; nothing is placed in browser code. Optional server variables: `GEMINI_SPEECH_MODEL` (default `gemini-3.8-flash`) and `GEMINI_TTS_MODEL` (default `gemini-3.8-flash-lite-tts`). Reviewed official REST formats support current-model WAV and legacy PCM conversion. Supported curated voices: Kore, Puck, Zephyr, Charon, Aoede, Leda; no voice cloning or URL proxy. Audio input is at most 2 MiB; TTS at most 2,000 characters, output at most 2 MiB, provider timeout 20 seconds. Split longer material manually; cancellation stops waiting but may not prevent provider billing.

Configuration status is not proof of working billing/quota or inference quality. Consumer Gemini/Flow subscriptions are not presented as unlimited API access. Transcription needs manual review and has no measured speaker diarization/timestamps; the existing text subtitle exporter keeps explicitly approximate editable timings.

Prefer short TTS passages (roughly 250 characters). At 24 kHz mono 16-bit PCM, the 2 MiB output limit is about 44 seconds; character count cannot guarantee duration. Longer output can be rejected after provider generation and still incur cost. The UI explains this before use; it never automatically chunks material or makes additional calls. The per-user request rate limit is not an aggregate project spending cap.

## Remaining boundaries

No claim of parity with every feature of commercial editors or hosted services: Markdown is an original safe subset, not full CommonMark; Calendar is local, Reminder requires an open workspace, API requests remain subject to CORS, install/offline depend on the browser/cache, local marketplace/plugins use only reviewed engines, Terminal Simulator is not an OS shell, and UI phrase preview is not arbitrary translation. Native mic/voice/clipboard/notification APIs need supported browsers and explicit permissions. Backend AI requires login, provider configuration and API billing/quota; paid generation quality was not tested.
