- Author: Quaternius

- Original download: https://drive.google.com/drive/folders/18m4KpzpEzhC9wl7jzr6dUc0N8Jozr79C

This release uses all 50 animated monster models. The glTF files were converted
to Meshopt-compressed GLB without changing the source license. Models are loaded
on demand by active hunt wave; the complete library is never preloaded.
