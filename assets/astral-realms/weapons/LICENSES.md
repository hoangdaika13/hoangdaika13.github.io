# Astral Realms Weapon Library

This directory contains 72 selected, web-normalized weapon assets. Every
third-party source in this release is dedicated under CC0 1.0; credit is not
required, but HH Platform keeps the original author and source for provenance.

## Quaternius Modular Weapons Pack

- Source: https://quaternius.com/packs/medievalweapons.html
- Author: Quaternius
- License: CC0 1.0 Universal
- Files used: 24 FBX weapon models, converted to normalized GLB.

## Quaternius Sci-Fi Modular Gun Pack

- Source: https://quaternius.com/packs/scifimodularguns.html
- Author: Quaternius
- License: CC0 1.0 Universal
- Files used: 20 assembled glTF weapons, converted to normalized GLB.

## Quaternius Fantasy Props MegaKit Standard

- Source: https://quaternius.itch.io/fantasy-props-megakit
- Author: Quaternius
- License: CC0 1.0 Universal
- Files used: 10 weapon/catalyst glTF models from the free Standard archive.

## Kenney Blaster Kit 2.1

- Source: https://kenney.nl/assets/blaster-kit
- Author: Kenney
- License: CC0 1.0 Universal
- Files used: 18 GLB blaster models.

The build pipeline adds only runtime transform nodes (`Grip_R`, `Grip_L`,
`Muzzle`, `BladeRoot`, and `BladeTip`), web LODs and Meshopt compression. It
does not change the source license.
